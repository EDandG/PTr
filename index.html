Prescription types

Not a fixed list — create, retarget or retire types here. "Pre-screened" types skip straight to Awaiting Labelling and Assembly when booked in; anything else enters at Awaiting Screening first. Each type carries its own turnaround target (one KPI per type, in hours and minutes) rather than a per-line rule. Tick "TTO"/"Inpatient" so the live queue's view switcher knows which category this type belongs to.

Danger zone — superuser only

Wipes every prescription, its full history, and the audit log. Sites, dispensaries, wards, prescription types, suspension reasons and user accounts are not touched. For pre-go-live testing only — there is no undo, and this contradicts "nothing is ever deleted" everywhere else in this app on purpose.
