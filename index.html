Prescription flags — superuser only

Attention flags staff can attach to a prescription — e.g. "Fridge item", "Controlled drug", "Transport required". Each needs a label and either an emoji or a small PNG/SVG icon. "Display order" just controls the sequence they appear in — lowest first. Images are stored inside the database as data URIs, so keep them small icons (64KB max, enforced by the database) — a large image would be sent with every queue row for every user.

Bulk import icons

Upload a .zip of images, or select several image files at once. Each file becomes a flag, with its label taken from the filename — flag-cold-chain.png becomes "Cold chain". Files already matching an existing flag name are skipped, so you can re-upload the same zip after adding new icons to it. Anything over 48KB, or not an image, is reported and skipped.

Pressure thresholds — superuser only

How many items waiting at a stage counts as amber or red, shown on the live queue as a pressure indicator so staff can see where help is needed, not just "we're busy". Counts active (non-suspended) items only.

Danger zone — superuser only

Wipes every prescription, its full history, and the audit log. Sites, dispensaries, wards, prescription types, suspension reasons and user accounts are not touched. For pre-go-live testing only — there is no undo, and this contradicts "nothing is ever deleted" everywhere else in this app on purpose.
